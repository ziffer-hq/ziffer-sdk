# Reporting a vulnerability

Write to hello@ziffer.io with "security" in the subject. Please do not open a public issue for a vulnerability.

Tell us what you found, which package and version (or which file here), and how to reproduce it. We answer every report, tell you what we will do about it, and credit you when the fix ships if you want to be credited.

This repository holds the source of the ZIFFER npm packages and the ZIFFER plugin for Claude Code. A vulnerability in the ZIFFER service itself is reported the same way.
